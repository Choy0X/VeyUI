# Changelog

## Unreleased

### Changed
- The Taste Skill web foundation (38 MB, 1,632 files) is no longer stored in this repository or in the installed skill folder. `skills/veyui/scripts/fetch_foundation.py` downloads the pinned commit once, on first use, rebuilds `foundation/` and refuses anything that does not match `data/foundation-manifest.json` byte for byte. The installed skill drops from about 41 MB to about 3 MB. The offline library, concept studio and design modules work without it; only the web construction tools need it (internet once, about 30 MB).
- The hero was rebuilt twice more on the owner's direction. It is now a dark, cinematic two-column hero: a large two-tone headline with the install command on the left, and a glass panel on the right that shows the same fictional product as typical agent output and as a designed page, split by a sweeping slanted divider (pause button, range control, drag and keyboard support). A cursor-following lime dot glow lights the background. The generic card deck, the pinned morph and the hero canvas field were removed. The sections after the hero now fade their content in only once their color wipe covers it, so no text straddles the seam.
- The landing page in `site/` was rebuilt with veyUI's own three-concept workflow. Two finished concepts were built and reviewed, and the "Concept Shuffle" direction was chosen. It is original code with scroll-driven scenes, a hero that morphs a generic AI page into a designed one, and one before and after example: a fictional product, Slackwater, that rearranges from a typical agent-made page into a designed tide dashboard as you scroll, with five named fixes. It replaces the page that was assembled from the Taste Skill kit. See `docs/site-case-study.md`.
- Preview images (`og-image.png`, `social-preview.png`, `preview-concepts.png`, `preview-workflow.png`) are now generated by `tools/previews/generate.cjs`.

### Added
- A new logo that matches the site: a lime tile with an ink outline and hard offset shadow, an ink V and a cobalt second stroke (the chosen one). Source is `site/assets/logo.svg`; `tools/brand/generate-icons.cjs` regenerates the favicon, touch icon and plugin icon.
- A scroll-driven before and after example (`site/assets/css/ba.css`, `site/assets/js/ba.js`) with a Before/After control, a scrub range, five named fix tags and a fix list. The After design was made from one of the owner's reference images, executed as original code. Reduced-motion and no-JS visitors get a complete static before and after.
- `tools/check_site.py` and a "Landing page checks" step in the Validate workflow (ASCII, JSON-LD, FAQ parity, local links, no third-party loads, social image sizes).
- GSAP (3.15.1) and three OFL font families vendored for the page, with notices in `THIRD-PARTY-NOTICES.md`.

### Removed
- The 13 Taste Skill kit files and `veyui.css` / `veyui.js` from `site/`. The skill itself still bundles Taste Skill unmodified, with credit.

## 1.0.0 - first public release

### Added
- Public repository layout: the skill lives in `skills/veyui/`, discoverable by the `skills` CLI, Claude Code plugins, Gemini CLI extensions and Agent Skills clients.
- Multi-agent installer `install.py` (plus `install.sh` and `install.ps1`) with `--agent`, `--all`, `--project`, `--skills-dir`, `--list` and `--dry-run`. Covers the folders of more than 20 coding agents.
- Native packaging: `.claude-plugin/` (plugin and marketplace), `.cursor-plugin/`, `gemini-extension.json`, `AGENTS.md`, `GEMINI.md`, `CLAUDE.md`, `.github/copilot-instructions.md`.
- Landing page in `site/` with SEO metadata, sitemap, `llms.txt` and social preview images. Deployed with GitHub Pages.
- Documentation: install guide, platform matrix, usage, how it works, FAQ, contributing references and maintainer publishing notes.
- `asset_withheld` field for catalog records whose images are inspected but not distributed.
- Credits and notices for Taste Skill by Leonxlnx (`THIRD-PARTY-NOTICES.md`, README, site).

### Changed
- `SKILL.md` description rewritten to be trigger-first and plain. Added `license`, `compatibility` and `metadata`.
- Wording that described private-project context was made neutral. Client project names were removed.
- Counts in the docs now match the data files: 19 decision guides, 384 catalog records, 583 reviewed screens, 200 patterns, 8 documented flows.
- `agents/openai.yaml` trimmed to documented fields.
- `references/agent-portability.md` now lists the full platform matrix.

### Fixed
- `scripts/verify_foundation.py` reported every file as untracked on Windows (path separator mismatch).
- `tests/reference_gallery_dom_regression.cjs` failed on Windows (CRLF in generated output) and now works without bundled images.

### Removed
- 31 owner-supplied concept screenshots and the generated `reference-library.html` gallery. Redistribution rights were unverified. The 31 concept studies stay as text notes.
- The old ZIP-based installer (`install-veyui.py`) and package notes.

### Foundation
- Web engine: Taste Skill 2.5.1 by Leonxlnx, commit `f6b76575f949707b4e3c37cd86cb44b0b98643e8`, 1,632 files, hash-verified and unmodified.

### Verification
- Python regression tests (32) and the minimal-DOM gallery checks pass without bundled images on Windows 11, Python 3.13, Node 25.
- Browser rendering of the bundled gallery and of every concept workflow was not part of this release check.
