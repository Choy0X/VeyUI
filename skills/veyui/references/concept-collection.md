## Use a concept in a new design

1. Retrieve a small set by platform and task, for example `python3 scripts/design_library.py concepts "workflow canvas inspector" --platform web`. Use the host's Python launcher and an absolute script path when working in another directory.
2. Pick one structural lead and one complementary precedent. Related crops and theme variations are grouped by family. A screenshot shows composition, while a separately checked live example establishes the planning link.
3. Write the project-specific translation as **reference ID | visible decision | target content and geometry | failure to avoid | rendered check**. For example, take R015's readable proof zone and adapt it to a review queue with a real approval and resulting audit entry. Protect those elements in the desktop crop and render the approval sequence inline on mobile.
4. Treat motion as a separate design decision. A still can suggest a stage or an anchor. Define the trigger, shared geometry, enter and exit states, cancellation and reduced-motion result, then inspect playback and operate the real controls. For a layered marketing scene, test that moving artwork never covers proof or actions. For a table or calendar, prioritize stable rows and selected context over decorative movement.
5. Borrow anatomy and composition. Write original copy and verify product claims. A reference can be visually strong and still contain irrelevant copy, tiny labels or unverified logos. Use approved media and identify what needs to be created.

The concept images are not shipped; these studies are text-only (see Images in the public release in the Reference library). Build a private gallery from your own images when you need to compare visual variants. The November collection includes 18 distinct studies from 20 source images. Two pairs share a composition or overlap substantially. Those pairs retain both source filenames in a single record. Theme and section variants remain separately labeled but contribute only one family per ranked result. Treat all records as visual studies with unverified release status and source rights.
