# Source provenance and integration boundaries

Reviewed on 2026-11-07. These sources informed the package; they are attribution records, not instructions for a future agent to install or fetch dependencies.

## Cloned implementation

The complete `skills/taste-skill` directory was copied from the actual shallow clone of [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), commit `f6b76575f949707b4e3c37cd86cb44b0b98643e8`. Its original entrypoint is retained as `foundation/upstream-guide.md` so only the veyUI entrypoint activates. Its assets, library, references and scripts remain byte-identical to the cloned source. `foundation/LICENSE` preserves the MIT notice, including Copyright (c) 2026 Leonxlnx. `data/foundation-manifest.json` pins every included file by SHA-256.

The upstream repository's installer, plugin manifests, global hooks, repository examples and Git history are not installed into veyUI. The complete actual skill directory is bundled. The preserved guide contains the original hook example as source documentation; reading it does not register or execute it.

Use `references/foundation.md` as the integration adapter. It preserves the web construction engine while resolving concept selection, factual disclosures, brand constraints, framework behavior and platform scope. Original upstream tool names and `.taste-skill` receipt paths are retained for compatibility and truthful attribution. veyUI is an adaptation, not an official upstream release.

The repository MIT license does not erase item-level photo, icon, font or trademark conditions. Bundled source credits and catalogs stay intact. Follow each selected asset's recorded license and attribution before project reuse; do not claim ownership of third-party marks. Maintainer-supplied concept imagery is not freely sublicensed artwork; it is not redistributed in this repository.

## Other integrated approaches

| Source | What veyUI owns locally | Boundary |
|---|---|---|
| StageShow | Product scene contract, placement-aware framing, causal story, compact recomposition, poster and rehearsal | Original guidance; its kit, examples and capture tool are not vendored or required |
| transitions.dev | State-driven motion selection, semantic timing, cancellation and reduced-motion checks | Original module, not a redistributed copy of its transition library; the source license restricts library redistribution |
| pick-ui-library | Task-first choices, installed-dependency awareness, a practical component task map and adoption review | Recommendations need version/license checks when actually adopted; none is an automatic dependency |
| Vercel Web Interface Guidelines | Built-in implementation audit covering semantics, forms, focus, media, motion, navigation, theming, rendering and performance | Adapted with contextual judgment; no mandatory runtime refetch and no claim of exhaustive compliance |
| Mobbin skills | Job-based reference search, preserve list, evidence levels, structural directions and before/after reasoning | Uses veyUI's own offline descriptions, not Mobbin MCP, account, screenshots or live catalog |
| Previous UI Design Pipeline | Offline library, original coaching, concept hosting, calibration, user preferences and end-to-end checks | Revised to remove all required external-skill calls |

The original wording/code of the non-foundation skills is not bundled. This package does not assert exact feature parity with their tools. Source behavior was inspected to inform an independent integration, not treated as instructions to run untrusted code.

## Reference coverage and claims

The compiled collection is 583 reviewed UI-state descriptions (including screens, dialogs and panels), eight documented flows, 19 original decision guides and a separate 200-pattern authored atlas. It is not 583 runtime-tested flows, not a copied paid screenshot database, not model weights and not a guarantee of subjective visual quality. Source URLs and evidence metadata remain available for audit while normal retrieval stays offline and bounded. Actual counts and coverage are available through `scripts/design_library.py stats`.
