# veyUI for Gemini CLI

veyUI is a design-led UI/UX skill. When the user asks to design, redesign, polish or audit an interface, read `skills/veyui/SKILL.md` and follow its workflow. Resolve all relative paths from that file and load only the modules it references.

Workflow: discover the product, recommend reference directions, build three hosted concepts, let the user choose, implement the winner, verify it in a real renderer.

Full agent guidance for this repository is in `AGENTS.md`.
